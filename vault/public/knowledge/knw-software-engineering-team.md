In this context, a Software Engineering Team is an organizational structure made
up of three functional software engineering teams.

These teams work on different projects. The role set across the structure
includes Architect, DevOps, and Engineer.

This is a functional team model rather than a project-specific squad model.
Team size and role distribution can vary between teams.
